Full 3D from many photos

Photograph one object from all sides (20 to 200 photos, about 70 % overlap) and get a Gaussian Splatting scene. Takes several minutes.

How it works
  1. The subject is cut out with a U²-Net segmentation model (falls back to GrabCut).
  2. A monocular depth network (Depth Anything V2, or MiDaS v2.1 as a fallback) predicts relative depth for every pixel.
  3. Pixels are back-projected through a pinhole camera, meshed, textured with the photo and mirrored to close the back.
  4. The same points are written as 3D Gaussians, so the result also opens in splat viewers.

One photo cannot see the hidden sides of an object, so the output is a relief ("2.5D") model. For a full 3D capture, the multi-view pipeline in the same repo turns photos taken from many angles into a Gaussian Splatting scene.
